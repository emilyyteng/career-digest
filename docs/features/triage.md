# Triage

Issues surfaced to the user that are still **unresolved**: the user hasn't answered, or said they'll decide later. This is not a backlog and not the default place to report issues. The end-of-task report is the default; an issue lands here only so it isn't lost. See `AGENTS.md` → Issues found during work.

Remove an entry when it becomes a ticket or is dismissed.

## Entry format

```
### <Short title> (surfaced YYYY-MM-DD)
- **Observed:** what and where (file:line or command)
- **Evidence:** output, steps
- **Blocks:** nothing | <ticket>
- **Suggested home:** <feature> | maintenance | not worth a ticket
- **Waiting on:** what the user needs to decide
```
